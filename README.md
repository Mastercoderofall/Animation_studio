# Animatix Studio

A lightweight, browser-based frame-by-frame animation editor.Projects are stored in the current session until exported. 
SO MAKE SURE TO EXPORT THEM!!!

## Features

- Brush, marker, airbrush, pixel, calligraphy, highlighter, shape, fill, eyedropper, eraser, and hand tools
- Brush opacity, flow, hardness, smoothing, stabilizer, and size controls
- HEX, RGB, and HSL color entry, color history, and preset/custom palettes
- Onion skin with previous/future frame counts, tint, and opacity controls
- Frame duplication, deletion, naming, grouping, duration, multi-selection, reordering, and copy/paste
- Canvas zoom and pan, playback, undo/redo, project import, and project export

## Shortcuts

- `Space`: play/pause
- `B` / `E` / `I` / `H`: brush / eraser / eyedropper / hand
- `F`: add frame
- `⌘` or `Ctrl` + `D` / `C` / `V`: duplicate / copy / paste frame
- `⌘` or `Ctrl` + `Z`, `Shift` + `⌘` or `Ctrl` + `Z`: undo / redo
